# 🗺️ Texas A&M Campus Building Map

A web mapp that displays campus buildings at **Texas A&M University**. This project visualizes spatial data in an easy-to-use interface with clickable building features, allowing users to view building names, abbreviations, and more.

## 🚀 Features

- 🌐 Web-based interactive map with a "Streets" basemap
- 🏢 Campus building locations visualized using a Feature Layer
- 📌 Clickable popups showing:
  - Building name
  - Abbreviation
- 📍 Map centered on Texas A&M main campus in College Station, TX


## 📍 Current Map View

- **Center:** Longitude `-96.339469`, Latitude `30.617492`
- **Zoom Level:** 13
- **Data Source:**  
  [Campus_Building Feature Service](https://services1.arcgis.com/qr14biwnHA6Vis6l/arcgis/rest/services/Campus_Building/FeatureServer)
