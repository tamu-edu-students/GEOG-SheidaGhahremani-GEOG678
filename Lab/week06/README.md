# Sheida Ghahremani - TAMU Interactive Map 🗺️  

This project is an **interactive web map** built using **Leaflet.js**, displaying **Texas A&M University (TAMU) buildings** with data from a **GeoJSON file**.  
It allows users to explore campus buildings with interactive features, including:  

✅ **Building Highlights:** Hover over buildings to see their names and abbreviations.  
✅ **Zoom on Click:** Click on a building to zoom in and focus on it.  
✅ **Custom Styling:** Buildings are displayed in **maroon**, representing TAMU colors.  
✅ **Interactive Info Panel:** Shows the building name and abbreviation dynamically.  

## 🔹 Features  
- 🏛 **GeoJSON Integration:** Loads TAMU building data dynamically.  
- 🎨 **Custom Styling:** Buildings are colored and styled for a better visual experience.  
- 🖱 **Mouse Hover Effect:** Highlights buildings when hovered over.  
- 🔍 **Zoom to Feature:** Clicking on a building zooms into its location.  
- ℹ **Info Control:** Displays building details on hover.
