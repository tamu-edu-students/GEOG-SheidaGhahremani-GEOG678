# My First Web Map 🌍

This project is an interactive web map built using **Leaflet.js**, showcasing key landmarks in **College Station, Texas**.  
It allows users to view a map, locate themselves, and explore **Texas A&M University** landmarks, including:

✅ **O&M Building** 🏢  
✅ **Academic Building** 🎓  
✅ **Evans Library** 📚  
✅ **Kyle Field** 🏈  
✅ **The Golf Club at Texas A&M** ⛳  

---

## 🔹 Features
- 📍 **User Geolocation:** Automatically detects and zooms to the user’s location (if permission is granted).  
- 🏛 **Custom Markers:** Highlights important Texas A&M University landmarks.  
- 🔵 **Kyle Field Circle:** Displays a **300-meter radius** around Kyle Field.  
- 🏞 **Polygon for Golf Club:** Marks the boundary of **The Golf Club at Texas A&M**.  
- 🖱 **Click-to-Get Coordinates:** Clicking anywhere on the map shows **latitude and longitude**.
