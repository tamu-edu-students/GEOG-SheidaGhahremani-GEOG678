# 🗺️ Brazos County Flu Vaccination Locator

Welcome to the **Brazos County Flu Vaccination Locator** — a WebGIS application that helps users easily find flu vaccination centers across Brazos County, Texas!

## 🌟 Features
- 🧭 Interactive map for easy navigation
- 🔍 Location search and nearby center discovery
- 🚗 Real-time routing between start and end points
- 🏥 Detailed information about each vaccination/testing center
- 💻 Built using **ArcGIS**, **Leaflet**, **HTML**, **CSS**, and **JavaScript**

This project aims to enhance public health accessibility by offering a simple, user-friendly, and map-based tool to locate flu vaccination and testing facilities.
